Call the API from this page

The CountOnce API is the service the staff app and the dashboard both talk to. Here you can send it the same requests they send and read its answers. These are real requests, and they change only your practice stock.

GET/api/state

Returns the real stock, its last 20 changes (the movements list) and the supplier orders. Anyone can read it. Open the raw JSON.


  


  

    
POST/api/moveTake items out of your practice stock, or put items in.

    
Each request carries an id in its request_id field. The staff app makes one on the phone at each scan. If the same request arrives again with the same id, the API changes nothing and replies with the first answer, marked "repeated": true.

The other routes

    
    
      
  • GET /api/history?item=GLOVE-M: one item's changes, with the stock after each.
    • 
      
  • POST /api/order: raises a supplier order if the item is at or below its reorder level and has no open order. The API decides how many to order.
    • 
      
  • POST /api/order/received: records a delivery. Sending it twice adds the stock once.
    • 
      
  • POST /api/visitor: creates a visitor's practice stock, or returns it if it already exists.
    • 
    

    
Changes to the real items need the x-staff-key header.
